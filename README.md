Overview

A real-time chat app where users sign in, join rooms, and exchange messages that appear instantly.

Key Features

Sign in securely and keep a persistent display name

Create and join chat rooms with descriptions

Send and receive messages instantly without reloading

See who is online in each room

Typing indicators and read receipts

Full chat history that survives refresh

Responsive layout for desktop and mobile
